# examples

The same building plan designed in three construction methods and printed to PDF. Load any of them into AZRAS Planning to try the drawing analysis and AI takeoff.

| File | Construction method |
|---|---|
| [260805_AZRAS.pdf](260805_AZRAS.pdf) | AZRAS (RC Upright Method) |
| [260805_2x6.pdf](260805_2x6.pdf) | Timber 2×6 |
| [260805_RC_Rahmen.pdf](260805_RC_Rahmen.pdf) | Conventional RC frame |

These files are byte-identical to the drawings sent to the AIs in the published sample projects (there, the timber file is named `260805_2×6.pdf`). The complete sample projects (saved results, regional variants and the multi-AI takeoff rounds) are a separate dataset on Zenodo (CC BY 4.0).

---
