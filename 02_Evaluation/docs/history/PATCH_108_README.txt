AZRAS PATCH 108
対象: 03_AZRAS_Evaluation / Module 6
基準: PATCH 087 Module 6（PATCH 088はModule 3のみのため競合なし）

家賃設定を2方式化:
1) 表面利回りから逆算（標準）
   初年度総家賃 = 初期投資額 × 目標表面利回り
   戸当たり月額家賃 = 初年度総家賃 ÷ 12 ÷ 総住戸数
   標準初期値 = 8.0%
2) 市場家賃を直接入力
   従来の年間賃料単価（JPY/m2・年）を使用

重要:
- 旧Project JSONで家賃設定方式が未保存の場合、次回Module 6計算時は
  新標準の「表面利回り8%」を採用。
- 旧annual_rent_per_m2値は削除せず、市場家賃方式へ切替時に利用可能。
- 表面利回りの分母は既存Module 6定義と同じ initial_total_investment
  （建設費税別 + 土地費 + その他初期費）。
- 土地建物関連税は従来方針どおりCFから除外。
- Module 6再計算後、CF・NPV・投資回収年・建替え時家賃損失等は新家賃条件で更新される。
