AZRAS System v2.2.0 初回環境設定

AZRAS Installer Version 5.0.4 自体の起動にPythonは必要ありません。

まずAZRAS Installerを起動してください。InstallerがPythonの有無を確認します。

AZRASのソース版起動・EXEビルドで必要となる外部ソフトは Python 3.13（64-bit） です。

  1. AZRAS Installerを起動します。
  2. Pythonが「検出済み」の場合は、追加インストールは不要です。
  3. Pythonが未検出の場合は、Python公式Windowsダウンロードページを開きます。
  4. Python 3.13系の「Windows installer (64-bit)」をダウンロードし、通常どおりWindowsへインストールします。
  5. AZRAS Installerへ戻り「再確認」を押し、Pythonが「検出済み」になることを確認します。

図面PDF

CAD等から直接PDF出力した詳細図PDFを使用します。紙図面をスキャンした画像PDFは原則対象外です。

AZRAS専用フォルダーへのPython登録や共通ツール設定ファイルの作成は不要です。
