AZRAS System v2.2.0 Initial Environment Setup

AZRAS Installer Version 5.0.4 itself does not require Python to start.

Start AZRAS Installer first. The Installer checks whether Python is installed.

Python 3.13 (64-bit) is required when running the AZRAS source edition or building an EXE.

  1. Start AZRAS Installer.
  2. When Python is detected, the same list shows the status of the Python packages each product uses (numpy, pandas, reportlab and others).
  3. If Python is not detected, open the official Python Windows download page.
  4. Install a Python 3.13 series Windows installer (64-bit) normally.
  5. Return to AZRAS Installer, click Check Again, and confirm that Python is detected.
  6. If any package required for Source edition start-up is Not Detected, click Install Command. Paste the command shown (it is also copied to the clipboard) into a Command Prompt and run it. The Installer never installs anything itself.
  7. Click Check Again and confirm that every package is detected before starting the products. With a package missing, Planning and Evaluation stop at start-up.

Packages marked Self-checks (optional) (pyflakes, jsonschema) are needed only to run dev_checks.

The distributed EXE edition does not require a separate Python installation.
