AZRAS Platform V9.0 Foundation
================================

正式モジュール構成
Module 0：AZRAS Core（共通データ）
Module 1：図面・数量・建物性能 共通解析
Module 2：環境・CO₂・エネルギー
Module 3：修繕・更新・解体シナリオ
Module 4：200年環境評価
Module 5：建設費
Module 6：100年投資評価
Module 7：修繕・解体積算
Module 8：200年事業収支

環境評価グループ
Module 1 → Module 2 → Module 3 → Module 4

事業評価グループ
Module 1 → Module 5 → Module 6
Module 3 → Module 7
Module 5・6・7 → Module 8

Module 0の範囲
- プロジェクトID・名称
- 国・都市・住所・地番・緯度・経度
- 用途・規模
- 各Moduleの出力参照
図面および材料仕様はModule 0に保存しない。
各Module出力をJSONで参照する。

Module 1の範囲
- 工法・用途を限定しない共通解析
- PDF図面読込
- 建物形状、面積、開口、材料数量
- 断熱性能
- 蓄熱量・有効熱容量
- 設備容量と年間使用条件
  照明、コンセント、空調、換気、冷蔵庫
- 出力をModule 2とModule 5で共通使用

重要
現在の断熱・蓄熱・設備電力量は企画比較用の暫定計算である。
正式評価では材料物性、部位構成、設備表、運転スケジュールを確認する。


V9.1 Module 2 実装内容
----------------------
- Module 1結果を共通プロジェクトJSONから取得
- EPWまたは8760時間CSV読込
- 3ノード縮約熱モデル
  室内空気・RC壁・床スラブ
- 外皮U値、窓、換気、熱交換、日射、内部発熱を反映
- 暖房負荷、冷房負荷、最大負荷
- 空調電力
- Module 1で設定した照明・コンセント・換気・冷蔵庫等の電力を加算
- 建物全体の年間電力
- 一次エネルギー
- 運用CO2
- 延床面積当たりの電力・CO2
- 時間別CSV出力
- Module 2結果を共通プロジェクトJSONへ保存

重要
地域プロファイルの電力CO2係数、一次エネルギー係数、地中温度は
初期テンプレートであり、最新の公的資料または電力会社等の値へ更新する。


V9.2 Module 3 実装内容
----------------------
- 費用を含まない修繕・更新・解体シナリオ
- 部材別点検・修繕・更新周期
- 設備更新：照明、コンセント、空調、換気、冷蔵庫
- スケルトン・インフィル分類
- AZRAS：RCコアを残し、インフィルと設備を段階更新
- 2×6、RCラーメン、RC壁式、鉄骨、CLT：設定年で全面建替え
- 建替え後の用途・規模は同一
- 間取りは将来需要に合わせて変更
- 残存・撤去・再使用・リサイクル割合
- Module 4およびModule 7へのデータ受け渡し


V9.3 Module 4 実装内容
----------------------
- Module 1材料数量による新築時環境負荷
- Module 2年間運用エネルギー・CO2の長期累積
- Module 3の全イベントを年別環境負荷へ変換
- 修繕、設備更新、インフィル更新、一部解体、全面建替え
- 廃棄物、再使用、リサイクル、最終処分
- 再使用・リサイクル控除
- 木材・CLTの炭素固定量を参考値として分離表示
- 30～300年等の任意評価期間
- 年別・累積タイムライン
- Module 4結果をModule 8等で利用できるJSON形式で保存


V9.4 Module 5 実装内容
----------------------
- Module 1数量を利用した新築建設費
- 材料費・労務費・機械仮設費
- 地域資材指数・労務指数・施工生産性指数
- 敷地・搬入・作業時間の施工条件補正
- 空調、電気、給排水衛生、キッチン、浴室等の一式設備費
- 諸経費、予備費、設計監理費、税
- 延床面積単価と想定工期
- 現地通貨方式、為替換算なし
- Module 5結果をModule 6・8で使用可能なJSONとして保存


V9.5 Module 6 実装内容
----------------------
- Module 5建設費を初期投資額として利用
- 50年間の賃料・空室・運営費・維持費・税・保険
- 賃料成長
- 借入比率、金利、元利均等返済、残高
- 最終年売却価値
- 事業NPV・IRR
- 自己資金NPV・IRR
- 表面利回り、NOI利回り、DSCR、単純回収年
- 年別キャッシュフローCSV
- Module 6結果をModule 8で使用可能なJSONとして保存
- Module 3の修繕・建替え費用はModule 7・8で別途統合
