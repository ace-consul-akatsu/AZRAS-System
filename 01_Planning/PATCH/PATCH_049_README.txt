対象ファイル:
  - core/csv_export.py（新規・02 Evaluation と同一）
  - lang/csv_ja.json（新規・CSV用の日本語見出し／コード値）
  - module1/app.py（詳細数量CSV）
  - module5/app.py（建設費内訳CSV）
  - regional_analysis/module10_ui.py（指定日時地域比較CSV）

要望内容:
  詳細数量CSVが英語で出るので日本語にしてほしい。その他のCSVも同様に日本語を出せるように。

方針:
  - CSV は「保存したときの画面の言語」で出力する。
      英語 … 見出し・値とも従来とまったく同じ（内部キーが見出し）。
      日本語 … 見出しを lang/csv_ja.json で日本語化。工事種別・単価状態などの
               コード値も日本語化。数値は一切変えない。
  - 訳が無い列は空欄にせず英語のまま出す（dev_checks で検出）。
  - Project JSON・計算結果の内部データは英語正本のまま（表示のみの変更）。
  - 共通処理は core/csv_export.py（01 Planning と 02 Evaluation で同一ファイル）。

変更:
  1. Module 1 詳細数量CSV
     日本語：項目・分類・根拠区分・算定根拠・参照元・図面根拠を「詳細数量」タブと同じ表示で出力。
     見出しは No./AZRASキー（英語正規名）/分類/項目/数量/単位/根拠区分/信頼度/算定根拠/
     参照元/図面・根拠資料/単価/通貨/金額/備考。
     AZRASキー列は英語正規名のまま（Project JSON の行と照合するため）。
     英語時の既定ファイル名を「_詳細数量.csv」から「_Detailed_Quantities.csv」に変更（日本語時は従来どおり）。
  2. Module 5 建設費内訳CSV
     日本語：見出し・行種別・単価表示区分・単価状態・数量出典区分・単価構成を日本語化。
     cost_item_key の直後に「工種・品目名」列を追加（画面の工種・材料別内訳と同じ名称）。
     英語時は列構成も従来どおり（品目名列は追加しない）。
  3. Module 10 指定日時地域比較CSV：見出しを日本語化。
  4. Module 2 8760時間比較CSV：見出しを日本語化（指標/現状/比較案/差/差%＝画面と同じ）。
     「比較結果を読込」は日本語見出し（指標）・英語見出し（metric）のどちらも読める。
     ※修正しないと日本語見出しの行がデータ1行目として読み込まれていた。

変更しないもの（確認済み）:
  - Module 2 月別暖冷房CSV・年間熱収支CSV：すでに日英併記。
  - 各表の右クリック「CSV出力」：画面の見出し・表示値をそのまま出すため、すでに画面言語どおり。
  - batch_analysis のマニフェストCSV、熱計算エンジン単体実行用CSV、旧takeoff v6_3 のCSV出力：
    画面から呼ばれていない（利用者の目に触れない）ため対象外。

注意（今回は変更していない）:
  - 詳細数量CSVは出力専用。CSVを取り込んで数量を入れる機能は無い。
    取込機能を追加する場合は仕様追加として別途相談。
