要望内容:
  Compare の範囲差で、2×6・RC に埋戻し・捨てコン・基礎下砕石・客土・残土処分が無い。
  内部の布基礎も伏図から測り、土工事が出るようにする。

原因（実データ 260929_2x6.json / 260929_RC_Rahmen.json と各PDFで確認）:
  RC : Module 1 は基礎伏せ見下げ図から地中梁長さ 60.65m を算定し
       rc_vector_takeoff.foundation.net_ground_beam_length_m に保存していた。
       Module 5 は member_geometry.ground_beam_length_m を読むが、このキーを書く処理が無く、
       土工事6項目が丸ごと計算されなかった（Module 5 記録：foundation_preparation_group missing_quantity）。
  2×6: 布基礎の総延長を「外周＋界壁本数×奥行」で推定していたため、区画を囲む内部の布基礎を
       拾えず、今回の図面では断面計測も成立せず foundation_geometry 自体が無かった。
       さらに Module 1 形式（concrete_volume_m3 が数値）を Module 5 が読むと例外で落ちる状態だった。

修正:
  1. RC：member_geometry に長さが無いとき、伏図ベクトル計測の地中梁長さ（解決済みのものだけ）を使う。
     使った長さの出所を drawing_supported.ground_beam_length_source に記録。
  2. 2×6：detect_2x6_strip_foundation_plan_vector を追加（旧処理は失敗時の代替として残す）。
     ・図面名「基礎伏図／基礎伏せ図／布基礎伏せ図／基礎伏せ見下げ図」の頁の線データを使う
     ・各区画は「立上り面の矩形」と「底盤端の矩形」の二重矩形で描かれる → 外側が区画
     ・立上り幅＝隣接区画の間隔、底盤幅＝立上り幅＋底盤はね出し×2
     ・芯々総延長＝（各区画の芯々周長の合計＋外周芯々）÷2
       （内部の布基礎は2区画で共有、外周は1区画 → 二重計上しない）
     ・縮尺は平面図の建物外形寸法と照合（幅・奥行とも1%以内でなければ不採用）
     ・高さは布基礎断面スケッチの寸法値（総高＝立上り高＋底盤厚）。伏図で測った幅が
       スケッチの寸法値と一致しなければ不採用
     ・区画が外形を隙間なく埋めない場合も不採用（布基礎の読み落とし防止）
  3. Module 5：2×6 の土工事が Module 1 形式の foundation_geometry を受け取れるようにした。
  4. Module 1（2×6）：伏図が解決したとき土間コンクリート面積＝立上り内側の面積
     （立上り部分は布基礎コンクリートに計上済みのため二重計上を防ぐ）。
     暫定の基礎・土間鉄筋の対象に「strip-footing concrete」を追加（従来は名称不一致で漏れていた）。
