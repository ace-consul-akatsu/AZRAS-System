対象ファイル:

要望内容:
  マルコ氏より、「位置ベースの建具寸法抽出、続けて作ります」との依頼。
  PATCH_031で「AG-1・AW-1・AW-3・AW-4・AW-5・SD-1・SS-1・SS-2の7記号は
  寸法が建具表内のCAD寸法線注記としてのみ存在しており、テキスト読み
  順の修正だけでは原理的に拾えない。ページ上のX/Y座標で記号と寸法線
  を対応付ける位置ベースの抽出処理が別途必要」と報告していた残課題
  への対応。

実装したロジック（実際のA-15建具表で1つずつ検証しながら設計）:
  1. 「形状寸法」の見出し語の位置を基準に、ページ自身の罫線（文字の
     位置ではなく実際の線オブジェクト）から、その見出しのすぐ上の
     横線（記号・形式・箇所数の行の下端）とすぐ下の横線（室名行の
     上端）を探し、「形状寸法」セルの縦方向の範囲を特定する。
  2. その範囲内にある縦の罫線（列の区切り線）を使って、各建具記号の
     列の正確なX範囲を特定する（記号ラベルの中間点で推測するより
     はるかに正確）。
  3. 列内にある単独の整数（寸法値）を、文字の外接矩形が横長か縦長か
     で「幅方向の寸法」「高さ方向の寸法」に自動分類する。CAD図面の
     寸法数値は必ずその寸法線の方向に合わせて回転して描かれるため、
     列内のどこにあるかを推測する必要が無い。
  4. 幅：候補のうち「他の候補の一部の合計と一致する値」（合計寸法。
     例：1800+100+1800=3700）を採用し、無ければ最大値を採用。
  5. 高さも同じ「合計一致」判定を行い、一致するものが無ければ
     「最も上（y座標が最小）にある」候補を採用する。実データを
     1件ずつ確認したところ、2つ目・3つ目の高さ候補は必ず「FLからの
     立上り高さ」等の別の基準線であり、建具自体の高さではないことが
     確認できたための採用。

既存パイプラインへの統合:

  「位置ベースの結果のconfidence(0.85)が、既存のテキストベース結果の
