要望内容:
  1. 同じ地域なのに案件ごとにAI単価が違う。最初の1件の複数AI単価を固定して使い回し、
     工法が違う部分だけを調べる。規模区分の列を持たせる。

  2. PDFが1枚でも変わったら図面一式を入れ直すので、「図面追加」ボタンは削除する。

対応:
  地域単価表
    保存先: <JSON保存フォルダー>\Regional_Unit_Price_Tables\
            AZRAS_UNIT_PRICE_TABLE_<地域>_<版>.json（例: AZRAS_UNIT_PRICE_TABLE_Japan_Nagoya_2026-10.json）
            案件フォルダーの外なので、旧図面のデータを移動しても表は動かない。
    照合キー: 品目 + 仕様 + 単位 + 規模区分
            仕様は、工法で仕事が違う4工種（型枠・コンクリート・鉄筋・フェノールフォーム）だけ工法名、
            それ以外は common（03 Compare の区分表と同じ一覧）。
    規模区分: 延床面積 S 〜300㎡ / M 〜3,000㎡ / L それ以上。境界値は表ファイルの scale_classes で変更可。
            別の規模区分の単価で代用しない（未登録としてAI調査へ回す）。
    Module 5 の新しい欄「地域単価表（同一地域の単価固定）」:
      ・地域単価表を適用（AI調査の前に）… 最新版を読み、登録済み品目を表の単価で値付け。
        未登録の品目だけが①〜⑥のAI依頼書の対象になる。すべて登録済みならAI調査不要と表示。
      ・AI採用単価を地域単価表へ登録 … 表が無ければ新規作成（版=現在の年月）。
        表があれば［はい］未登録品目だけ追加（登録済みは上書きしない、違いは一覧表示）／
        ［いいえ］新しい版（例 2026-10.2）を作り、このProjectのAI採用単価で置き換え。登録後このProjectにも適用。
      ・地域単価表の内容を確認 … 版・規模区分・登録品目の一覧。
      ・地域単価表の適用を解除 … 適用前のAI単価に戻す。
    登録できるのはAIが採用した単価だけ（比較前提表・手動入力の単価は登録しない）。
    設備一式は延床面積あたり単価で採用されたものだけ登録（1棟分の一式金額は他の建物へ移せないため）。
    通貨が違う表は使えない。地域プロファイルが案件所在地の都市でない場合は確認してから進む。
    単価根拠情報（price_basis_fingerprint）に表の地域・版・SHA-256・規模区分を記録し、
    basis_token に regional_unit_price_table / regional_unit_price_table_with_ai_items /
    mixed_regional_unit_price_table_and_regional_database を追加。表の単価は「概算・暫定」（黄色）表示。

  図面追加ボタン
    Module 1 から削除。図面を変えるときは「PDF/ZIP読込」で図面一式（複数PDFの同時選択またはZIP）を入れ直す。
    register_drawing_files の追加モード（replace=False）は呼び出し元が無くなったが、
    古い呼び出しで落ちないよう処理は残した（次回の横断監査で削除候補）。
